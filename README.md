Solidity Proposal Struct Challenge

Overview

This project demonstrates a basic Solidity structure for managing proposals. It extends the "Proposal" struct with a "title" field of type "string", allowing each proposal to have a short title alongside its longer description.

Smart Contract

The "Proposal" struct contains:

- "title" ("string"): A short title for the proposal.
- "description" ("string"): A detailed explanation of the proposal.

Code Example

struct Proposal {
    string title;
    string description;
}

Learning Objective

The objective of this challenge is to understand Solidity structs and how to add fields to existing data structures.

Status

Beginner Solidity learning challenge.

This repository is a learning exercise and is not intended for production use.
